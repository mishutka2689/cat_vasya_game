# cat_vasya_game
В представленном коде реализована игровая система, включающая основные игровые сущности, персонажей и магическую систему.

Базовые игровые сущности: Определён абстрактный класс Unit для юнитов, включая класс Monster, который реализует методы для расчёта здоровья, урона и защиты.

Персонажи: Создан класс Character, который поддерживает три архетипа (воин, маг, охотник). Для каждого класса рассчитываются уникальные характеристики, такие как здоровье, урон и манапул.

Магическая система: Определён абстрактный класс Spell с конкретными заклинаниями (Fireball, IceLance, LightningBolt, HealingWave), каждое из которых имеет урон и стоимость маны.

Тестирование: Включены тесты, которые проверяют создание монстров и персонажей, функциональность магической системы, невозможность создания экземпляров абстрактных классов и обработку ошибок при неправильном классе персонажа.
